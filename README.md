# 化学之王 Chemical Combo · 单机网页复现版

根据桌游《化学之王》的《游戏指南》（`化学之王游戏手册.docx`）与《规则补充》（`规则补充.docx`）
复现的单页 HTML 游戏，**双击 `index.html` 即可在浏览器中游玩**，无需服务器、无需联网、无外部依赖。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面入口（双击即玩） |
| `style.css` | 样式 |
| `data.js` | 手工整理的物质牌表 + 手写经典反应 |
| `reactions-data.js` | **自动生成**的扩充物质与反应库（由 `tools/gen-reactions.js` 生成） |
| `ion-data.js` | 离子母表（供生成器穷举复分解反应） |
| `game.js` | 规则引擎（出牌判定、反应链、特殊牌、DLC 指示、结算）+ 电脑 AI |
| `ui.js` | 界面逻辑（手牌排序、可行动作、选择器、换人遮罩、规则弹窗） |
| `tools/gen-reactions.js` | 反应库生成器 |
| `test/` | 自动化测试与化学审查报告 |

## 一、运行方式

1. 打开 `index.html`（Chrome / Edge / Firefox 均可，直接双击即可，file:// 协议下也能正常运行）。
2. **欢迎界面**先出现，提供三个选项：

   | 选项 | 说明 |
   | --- | --- |
   | 🔬 开始游戏 | 进入实验设置面板 |
   | 📖 规则介绍 | 打开规则弹窗（卡牌构成、出牌判定、特殊牌、人物/操作 DLC 指示、易混淆事项） |
   | 🧑‍🔬 制作人员 | 原作与规则来源、卡牌设定、网页复现实现说明、数据规模与致谢 |

3. 「开始游戏」后在设置面板中选择：游玩人数、实验方式、DLC 启用情况、对手、电脑间隔、
   科学家昵称、记牌器、是否明牌。
4. 点击「开始实验」。

> 设置面板为**左右两列**：左列「🧪 牌局构成」（人数 / 实验方式 / DLC / 对手），
> 右列「⚙ 界面与体验」（电脑间隔 / 昵称 / 记牌器 / 明牌），底部为「开始实验」按钮。
> 左上角「← 返回」可回到欢迎界面；游戏中点顶部「🔄 重新开始」也会回到欢迎界面。
> 窗口宽度小于 720px 时自动改为单列。

> 数据、规则引擎与界面分别是 `data.js` / `reactions-data.js`、`game.js`、`ui.js` / `style.css` / `index.html`。

## 二、已实现的规则

### 卡牌（严格按《游戏指南》第 3~4 部分）

| 类别 | 基础牌 | 物质 DLC |
| --- | --- | --- |
| 酸 Acid（Ad） | HCl×5、H₂SO₄×5、HNO₃×4、HF×1 = 15 | CH₃COOH、H₂C₂O₄ |
| 碱 Base（Be） | NaOH×5、Ca(OH)₂×3、KOH×2、Ba(OH)₂×2、NH₃·H₂O×2、Cu(OH)₂×1 = 15 | Mg(OH)₂、Fe(OH)₃ |
| 盐 Salt（St） | Na₂CO₃×3、CaCl₂×3、AgNO₃×3、CuSO₄×2、BaCl₂×2、NH₄NO₃×2、CaCO₃×2、FeSO₄×2、FeCl₃、Mg(NO₃)₂、Ba(NO₃)₂、NaHCO₃、CuCl₂、NH₄HCO₃ = 25 | Cu(NO₃)₂、NaCl、ZnSO₄ |
| 氧化物 Oxide（Oe） | H₂O×3、CO×2、CO₂×2、Fe₂O₃、CaO、CuO = 10 | Al₂O₃ |
| 单质 Element（Es） | O₂×3、H₂×2、Fe×2、Cu×2、Al、Cl₂、Na、Zn、Mg、C = 15 | K、Ag |

合计 **基础物质牌 80 张 + 物质 DLC 10 张 + 特殊牌 5 张 + 人物 DLC 5 张 + 操作 DLC 5 张 = 105 张**。

牌面信息包括：化学式、物质名称、类别角标（Ad/Be/St/Oe/Es）、溶解性（✔ 可溶 / … 微溶 / ✘ 难溶 / — 遇水反应或本身是水）、
状态（固 / 液 / 气）、腐蚀性、挥发性、常温自发分解、物质说明，以及 DLC 标记。

### 玩法

* **接龙实验 ★★★★★**（默认）：出牌必须能与上位反应的生成物之一反应；可一次出多张牌组成一个反应的全部反应物；
  出牌时**不考虑化学计量数**；实验台上多个生成物时下家可任选一个。
* **接力实验 ★★★★**：每次只能出一张牌。判定对象是**上家所出的那张牌**，而不是上位反应的生成物 ——
  你出的牌必须能与上家刚出的那张牌反应（实验台上的生成物仍会显示，但本玩法不作为接力目标）；
  也不能把上家刚出的那张牌原样再出一遍充数。当前接力目标会显示在实验台上方（「🎯 接力目标：必须与上家所出的 X 反应」）。
* **元素接力 ★★**：所出牌须与上一张牌有一种或多种相同元素（自动禁用人物 / 操作 DLC）。
* **开局起牌（麻将式）**：实验台上没有可反应物质时，本回合第一位科学家**只出一张牌铺垫，这张牌不参与任何反应**
  （即使它本身可以自发分解、或能与上一轮台上的残留物反应）；由下一位科学家决定出牌与它反应、还是 Pass。
  也就是说，**一轮真正的反应至少要经过两位科学家**。
* **Pass**：**只有在场科学家全部 Pass 之后**，实验台上的药品才倒入废液缸并开启新一轮。只要还有人没 Pass，
  台上的物质就仍然有效，后面的人依旧可以出牌与它反应；一旦有人出牌，Pass 计数清零。
  界面上会实时显示「本轮 Pass：x/y」，以及"已有 x/y 位科学家 Pass（全部 Pass 后才倒入废液缸）"的提示。
* **手牌排序**：手牌、底部手牌一览都按「牌的种类 + 在相应表中的次序」排列 ——
  特殊牌 → 人物 DLC → 操作 DLC → 物质牌（任意物质 → 酸 → 碱 → 盐 → 氧化物 → 单质，表内次序），同种牌相邻。
* **胜负**：出完全部手牌者胜利并成为旁观者；仅剩一位科学家时其出局，实验结束。
* **出牌顺序**：牌最多者先出（并列随机），顺时针进行。
* **反应判定**：内置 2000+ 条初高中化学反应（物质库 259 种）；置换反应按金属活动性顺序穷举、双水解反应单独生成。出牌后自动显示反应物、生成物、反应条件与反应名称。
  右侧「反应参考」可按物质名 / 化学式查询该物质能参与的全部反应。
* **不含分解反应**：按需求，反应库中**没有任何分解反应**（过氧化氢/氯酸钾/高锰酸钾制氧、电解水、
  碳酸钙高温分解、碳酸氢盐与氢氧化物受热分解、硝酸盐受热分解、电解熔融氧化铝/氯化钠等均已移除）。
  生成器在生成阶段与过滤阶段各做一次拦截，测试里也有对应校验。

### 卡牌分类与配色

物质牌按化学类别着色（卡面上方色条 + 记牌器小卡描边）：

| 类别 | 代码 | 颜色 |
| --- | --- | --- |
| 酸 | `Ad` | 橙色 |
| 碱 | `Be` | 蓝色 |
| 盐 | `St` | 青色 |
| 氧化物 | `Oe` | 金色 |
| 单质 | `Es` | 紫色 |
| **其他** | `Ot` | **白色** |

「其他」用于既不是酸/碱/盐、也不是氧化物或单质的常见物质：**氨气 NH₃、甲烷 CH₄、
乙醇 C₂H₅OH、乙炔 C₂H₂、四氟化硅 SiF₄** —— 这样 NH₃、CH₄ 之类不会被误标成「氧化物」。

### 特殊牌（《规则补充》）

| 牌 | 效果 |
| --- | --- |
| **任意物质 ×2** | 可代替物质牌表中的任意一种物质；打出时须先指定所代替的物质，否则不予反应 |
| **抵消 ×1** | 抵消一次行动：有人打出人物 / 操作 DLC 时，出此牌即视为完成相应要求；若人物与操作 DLC 均未启用，则可抵消本轮反应并开启新一轮（由出该牌者出牌） |
| **转换 ×1** | 将一种物质牌转换为至少含有一种相同元素的另一种物质（程序会按元素过滤可选目标） |
| **回收 ×1** | 在废液缸中随机抽取一张物质牌加入手牌 |

特殊牌在任意出牌轮均可发动，且不计入出牌次数。

### 人物 DLC（《规则补充》）

| 化学家 | 指示 | 不出牌惩罚 |
| --- | --- | --- |
| J. J. Priestley | 打出一张氧气或氧化物物质牌 | 停 2 回合 |
| R. Boyle | 打出一张盐物质牌 | 停 2 回合 |
| G. N. Lewis | 打出一张酸或碱物质牌 | 停 2 回合 |
| 侯德榜 | 打出氨碱法（NH₃+CO₂+NaCl+H₂O=NaHCO₃+NH₄Cl）6 种物质之一（NH₃·H₂O 也算） | 停 1 回合 |
| 徐寿 | 打出一张单质物质牌 | 停 2 回合 |

打出该牌的科学家无需再次出牌；其他科学家须出牌或接受停牌惩罚；全部行动完后由**出牌者的下一位**开启新回合。

### 操作 DLC（《规则补充》）

| 操作 | 指示 | 惩罚 |
| --- | --- | --- |
| 过滤 | 一张微溶或难溶物质牌 | 停 1 回合 |
| 蒸馏 | 一张液体物质牌 | 停 1 回合 |
| 溶解 | 一张可溶物质牌 | 停 2 回合 |
| 集气 | 一张气体物质牌 | 停 1 回合 |
| 蒸发 | 一张可蒸发结晶的可溶物质牌（**排除** NaHCO₃、NH₃·H₂O、NH₄NO₃、Cu(NO₃)₂、FeSO₄） | 停 2 回合 |

### 《规则补充》里的易混淆事项

初始抽牌「一人一张、依次抽完」；Pass 掉的是**当时实验台上要求你反应的那张/那些物质**
（本程序按「在场科学家全部 Pass 后」才把台上药品倒入废液缸）；
实验台多个生成物时下家可任选其一；「任意物质」只能代替**物质牌表内**的物质；
打出 DLC 牌的科学家无需再出牌，其余科学家仍须出牌或受罚，之后由其下一位开启新回合；
胜利后其余科学家继续，直到只剩一人出局。以上均已在程序内实现，并可在「📖 规则」中查阅原文。

## 三、界面

* **顶部**：药品柜（剩余牌堆）、废液缸、回合数，以及**回溯（悔棋）** / 规则 / 物质总表 / 重新开始。
* **左栏**：科学家列表（手牌数、停牌、已出完、电脑标记）与逐条实验记录。
* **中间**：实验台 + 反应式条文；下方为我的手牌（按类别与表内次序排列）。
* **右栏**：**可出的牌**（列出当前真正能出的牌及原因，点击即选中）与可行动作、反应参考查询。
* **底部**：记牌器（可在开局时关闭或改为只显示总手牌数）。
* 快捷键：`Enter` 出牌，`Esc` 关闭弹窗。

### 出牌交互

1. **选牌**：点击手牌选中（可多选凑齐一个反应的全部反应物）。**当前不可出的牌会灰显**，右边「可出的牌」列出所有能出的牌。
2. **选择反应对象**：若台上有多种物质都能与所出的牌反应，实验台上所有可反应物质会**高亮**（金色描边 + 「↑ 点此反应」），
   同时反应式条文实时显示**当前选中的那个反应的方程式**。点击另一个高亮物质即可换反应对象。
3. **确认**：点击 **出牌** 键才真正出牌。**特殊牌、人物 DLC、操作 DLC 也必须先选中再按出牌键确认**，不会点一下就生效。
4. **Pass** 键与出牌键在同一行。**Pass 规则**：一轮里，**除本轮最后出牌的科学家以外**的在场科学家全部 Pass 后，
   实验台上的物质才倒入废液缸，并由**最后出牌的那位科学家**开启新一回合。
   例如 3 人局 A 出牌 → B、C 各 Pass 一次就满足条件，回合回到 A；
   若 A 出牌后 B 又出了一张并发生反应，则回合回到 B（因为最后出牌的是 B）。
   如果最后出牌的那位已经出完牌或手里没有可出的牌，则顺延给下一位在场科学家。
5. **回溯（悔棋）**：顶部「↩ 回溯」会**回滚到上家上一次出牌之后**，即撤销你自己上一次操作
   （出牌 / Pass / 用特殊牌 / 响应指示 / 接受惩罚）。回溯时会同时还原随机数状态，因此电脑的后续行为保持可复现；
   操作被规则拒绝时不会改变回溯点。

## 四、选项说明

* **全部电脑**：观战模式，所有座位由电脑托管，可直观看到完整对局。
* **1 位真人 + 电脑**：由你操作 1 号座位（科学家 A）。
* **全部真人（同一设备轮流）**：所有座位都是真人，共用一台设备按顺序传牌。轮到谁时会先弹出**换人遮罩**
  （显示"轮到 科学家 X"、当前实验台可反应物质、轮次与废液缸情况），点击「我准备好了，显示手牌」后才显示他的手牌，
  避免下一位玩家提前看到牌；他一行动完（出牌或 Pass）立刻再次弹出遮罩交给下一家。响应 DLC 指示时同样会换人。
* **科学家昵称**：开局面板可为 5 个座位分别填写昵称，留空则用默认「科学家 A/B/C…」。
* **电脑出牌间隔**：滑块可自定义电脑思考时间（0 秒 = 立即出牌 … 4 秒），对真人座位无影响。
* **是否启用记牌器**：关闭后底部牌区整体隐藏。启用时可再选：
  * **是否展示牌的种类（颜色）**：不勾选时底部所有牌统一显示为灰色牌背，只看得到张数；
  * **展示模式**：`仅展示总手牌数`（一行汇总在场手牌总数 / 药品柜 / 废液缸）或 `展示各科学家手牌数`（每位科学家一行）。
* **是否明牌**：明牌时底部会显示所有人的具体手牌，便于教学 / 复盘（全部真人模式下仍会在响应阶段隐藏他人手牌）。
* DLC 建议在 4 人及以上时启用（与《游戏指南》一致，程序不做限制）。

## 五、开发者：数据生成与自动化测试

### 反应库是怎么来的

反应库分两层，避免手工枚举出错：

1. `data.js` —— 手工整理的物质牌表、手写经典反应（`REACTIONS` 前 168 条）。
2. `tools/gen-reactions.js` + `ion-data.js` —— **生成器**：用离子表穷举「阳离子 × 阴离子」的复分解反应
   （按“生成沉淀 / 气体 / 水”判定是否发生，且要求反应物都可溶），再枚举初高中常见反应族
   （中和、酸+金属、酸+金属氧化物、碱+盐、盐+盐、置换、氧化还原、分解、电解、氨碱法…），
   最后做相关性过滤（至少一种反应物是物质牌表内的物质）、范围白名单过滤与去重，输出 `reactions-data.js`。

```bash
node tools/gen-reactions.js      # 重新生成 reactions-data.js
```

生成器会打印新增物质数、穷举反应数、保留数与剔除数。修改母表（`tools/gen-reactions.js` 的 `EXTRA`/`MORE`/`T`，
或 `ion-data.js` 的离子表）后重新运行即可，无需手改生成结果。

### 数据一致性保障（生成器自动完成）

1. **化学式唯一化**：按「忽略书写顺序」归一后的化学式（`Ca(NO3)2` 与 `(NO3)2Ca` 视为同一物质）
   合并别名，只保留一个规范 id；`data.js` 手写反应里的 `Ca(NO3)2`、`(NH4)2SO4` 等别名写法
   也会被自动改写成规范 id（`CaNO32`、`NH42SO4`）。否则同一物质会有两个 id，界面上取名称解析不到、
   直接显示成 id。
2. **中文名称规范化**：盐名按「酸根名 + 阳离子名」生成（SO₄²⁻ + Ca²⁺ → 硫酸钙），
   酸名单独给出（HCl → 盐酸、H₂C₂O₄ → 草酸、NH₃·H₂O → 一水合氨、KClO → 次氯酸钾）；
   不存在或双水解的化学式（NH₄OH、HHCO₃、Al₂S₃、CuCO₃、AgClO 等）直接不生成，
   次氯酸银/铝/铁/铜等只作为产物出现、不作为反应物。
3. **书写顺序与母表一致**：含氧酸根写在阳离子之前（Na₂CO₃、Ca(NO₃)₂、(CH₃COO)₂Ca），
   次氯酸根 / 高锰酸根 / 偏铝酸根按 NaClO、KMnO₄、NaAlO₂ 书写，单原子酸根按 MgCl₂、FeS 书写。

### 置换反应怎么来的

生成器里的 `buildDisplacement()` 按**金属活动性顺序**（K Na Mg Al Zn Fe Cu Ag）穷举三类置换反应，
因此不会漏项：

1. 金属（活动性在氢之前：Mg / Al / Zn / Fe）+ 稀盐酸 / 稀硫酸 → 盐 + H₂；
2. 较活泼金属 + 较不活泼金属的**可溶**盐溶液 → 新金属 + 新盐
   （例如 Mg / Al / Zn / Fe 置换 CuSO₄、CuCl₂、AgNO₃、FeSO₄、FeCl₂、Al₂(SO₄)₃ 里的金属）；
3. 特别活泼金属（K、Na）与水 → 碱 + H₂。

反向（不活泼金属置换活泼金属）与难溶盐参与置换会被自动排除。

### 双水解反应怎么来的

弱碱阳离子（Al³⁺、Fe³⁺）与弱酸酸根（CO₃²⁻、HCO₃⁻、AlO₂⁻、SiO₃²⁻、S²⁻、SO₃²⁻）在同一溶液中会
互相促进水解，反应进行到底，例如：

```
AlCl₃ + Na₂CO₃ = Al(OH)₃↓ + CO₂↑ + NaCl            （条件：水溶液中）
Al₂(SO₄)₃ + 3Na₂S = 2Al(OH)₃↓ + 3H₂S↑ + 3Na₂SO₄
```

生成器用 `buildDoubleHydrolysis()` 按「铝盐/铁盐 × 弱酸盐」穷举，并做了两件事保证正确：

* 复分解穷举里**排除**这些离子对，因此不会再出现写成 `Al₂(CO₃)₃` 的错误产物；
* 水写进反应**条件**而不是反应物 —— 否则出牌时还得凑一张「水」牌才凑得齐反应物。

当前规模：**物质 259 种**（其中物质牌表 50 种可直接摸到）、**反应 2031 条**（置换反应 41 条、双水解 48 条）。
每条反应都带：反应物、生成物、反应条件、反应名称、反应类型；物质带化学式、名称、类别、
状态（固/液/气）、溶解性（可溶/微溶/难溶/遇水反应）、元素组成与说明。

## 六、已知限制

1. **规则判定依赖内置反应库**（当前 2031 条）。手册规定「不能确定能否反应的，以附录-溶解性表及
   “烧杯”APP 为准」，程序无法穷举所有反应；反应库由 `tools/gen-reactions.js` 生成，
   可按同一格式增补母表后重新生成。生成库已按高中范围做过过滤，但仍可能残留个别冷门组合，
   若发现错误请在生成器的母表里修正。
2. 反应式按玩家实际出牌显示，**不写化学计量数、不标 ↑/↓**（手册规定出牌时不考虑化学计量数），
   属于有意的简化取舍。
3. **开局起牌**按「只出一张、且不参与反应」实现：实验台上没有可反应物质时只接受单张物质牌，这一张不触发反应。
4. **Pass** 按你的要求实现为「全部在场科学家都 Pass 之后才清台」；一旦有人在中间出牌，Pass 计数清零。
5. **接力实验**的判定对象是「上家所出的那张牌」（`st.relayCard`），不是上位反应的生成物；
   同时要求本次所出的牌**至少有一张真正参与反应**（避免"反应完全靠台上残留物"的假判定）。
5. 电脑 AI 为启发式策略（优先完成反应、必要时回收 / 转换 / Pass），不追求最强棋力。
6. 《游戏指南》中的「物质推断」「保留实验」两种玩法未实现（依赖人工判定，不适合自动化）。
7. 【回收】会把废液缸中的记录抽回手牌；当牌堆已抽空且该记录原本不是牌（是废弃的生成物）时，
   引擎会补一张新的物质牌实例，此时牌张核算可能出现 ±1 的账面误差，不影响实际对局。
8. 全部真人模式下，每次换人、以及每次响应 DLC 指示都会弹出换人遮罩（开局第一位真人除外，
   因为此前没有需要隐藏的牌）；若想免去反复确认，可改用「1 位真人 + 电脑」模式。
9. 本环境沙箱禁止启动浏览器进程，因此没有界面截图；界面正确性由 `test/ui-smoke.js` 的 DOM 桩测试保证，
   视觉效果仍需在本地浏览器中确认。
